# 04 · 详细设计

## 时间和状态机

`time` 为窗台逻辑秒，`wall` 为已结算的浏览器时间戳（毫秒）。清晨、正午、傍晚各占 80 逻辑秒，周期为 240 秒。普通在线时每实秒推进一逻辑秒。「等 30 秒」附加 30 逻辑秒，时段按钮推进到目标时段的下一个起点。离线按完整秒补算，最多计算 1,800 秒，并更新真实结算时点，防止刷新反复补算同一次离线。

```text
锁定 → 空位 → 发芽 → 展叶 → 孕蕾 → 成熟 → 空位
                                          ↘ 花架 → 售卖
                                          ↘ 售卖
```

展叶阈值为 22%，孕蕾为 66%，成熟为 100%。成熟后停止消耗，处理后释放盆位。显示视角独立于植物进度，关闭特写即释放临时渲染资源。

## 成长计算

每个逻辑秒先按当前时段采样，再扣除自然消耗。数值限制在 0–100。

| 量 | 公式或规则 |
| --- | --- |
| 光照 | `clamp((时段基础光照 + 盆位偏移) × 光照模式倍率)` 后四舍五入。基础值为 `59 / 88 / 37`，偏移为 `0 / 9 / -15`，倍率为 `0.72 / 1 / 1.24`。 |
| 环境适配度 | 湿度、养分和光照分别按 `1 - abs(实际 - 理想) / 100` 计算，再取平均。 |
| 成长进度 | 每秒增加 `(0.58 + 0.54 × 适配度) / 物种基础秒数`。试玩物种基础时长为 100、125、145 秒。 |
| 土壤湿度 | 每秒减少 `盆器排水系数 × (0.10 + 光照 × 0.0017)`。浇水时加 26。 |
| 土壤养分 | 每秒减少 `0.13`。施肥时加 22。 |
| 成熟品质 | `round(100 × 适配度累计和 / 样本数)`。品质决定模型体量、成熟分枝数、价格和异色概率。 |
| 异色 | 播种时生成 32 位随机种子。成熟时以种子派生固定抽样，阈值为 `0.05 + 0.16 × 品质 / 100`。 |
| 售价 | `round(物种基价 × (0.70 + 0.45 × 品质 / 100) × 异色倍率)`。普通倍率为 1，异色为 1.6。 |

生长速度有下限，因此任何有效养护组合都可成熟。自然消耗与采样使单次临成熟操作的影响有限。三种物种的湿度、养分和光照理想值分别为洋甘菊 `58/57/64`、薰衣草 `43/60/76`、紫叶酢浆草 `66/65/48`。

## 数据与事务

| 结构 | 字段 |
| --- | --- |
| 存档 V1 | `version`、`gardenId`、`revision`、`time`、`wall`、`coins`、`slots`、`shelf`、`album`、`achievements`、`likes`、`stats` |
| 盆位 | `unlocked`、`plant`，用内容 ID 索引 |
| 植株 | `species`、`pot`、`seed`、`moisture`、`nutrition`、`exposure`、`growth`、`score`、`samples`、`quality`、`rare` |
| 展品 | `species`、`pot`、`seed`、`quality`、`rare` |
| 图鉴 | 按物种保存成熟总数 `count`、异色数 `rare`、最佳品质 `best` |
| 分享 V1 | `v`、`id`、`plants`，最多八项展品，通过 URL 片段里的 Base64URL 传输 |

控制器提交 `type` 及必要参数。`plant` 校验 ID、余额和空位，再扣款并创建植物。`sell`、`display`、`move` 带预期种子，防止列表或盆位变化后处理错误对象。成熟、图鉴及里程碑在同一个规则事务内结算。对端输入的花架快照有大小、版本、字段和值域校验，只在访客视图中使用。

有 Web Locks 的浏览器在同源存档锁中读入、补算、应用动作和写入一份 JSON。不支持 Web Locks 的环境使用同步本地事务，建议单标签运行。存储不可用或解析失败时显示临时模式提示，保留原始存档。V1 解码拒绝未知版本，为今后迁移留出版本边界。

## 场景与输入

- 场景使用固定透视相机，窗口尺寸变化时重算视野和盆位标签投影。点击模型区域使用射线选取，键盘可通过标签和手记进入同一特写。
- 窗外画布纹理按时段生成。半球光和方向光控制色温及窗框阴影，光束叠加层表现入射路径。盆栽仅在阶段或外观参数变化时重建，窗口场景按需渲染。
- 特写使用独立相机与 OrbitControls，限制缩放范围。弹窗开启时背景控件不可交互。WebGL 不可用时仍显示插画、位置、养护和交易操作。
