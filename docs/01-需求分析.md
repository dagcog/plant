# 01 · 需求分析

## 产品定位

《窗边小事》是一款轻度种植和收藏游戏。玩家拥有一扇会随时间变色的窗，在有限的种植位上尝试不同盆器、光线和养护方式，再决定把长成的盆栽留给自己，还是卖出换取下一轮的种植预算。

目标用户是喜欢植物、空间布置和慢节奏收集的玩家。常规回访以 1–3 分钟为目标，一次可完成查看状态、少量养护、成熟处置中的任意几项。完整养成需要多长时间、玩家愿意隔多久回来，由试玩反馈校准。

## 试玩需求与验收

| 优先级 | 玩家需求 | 可观察的验收结果 |
| --- | --- | --- |
| P0 | 在窗边感受到时间变化 | 场景有清晨、正午、傍晚，天空色、直射光、窗框投影和光束方向可辨认。每个时段也有文字标签。 |
| P0 | 开出新种植位 | 开局两个种植位可用，花 48 叶币解锁第三个。余额不足或已解锁时无法重复扣款。三个位置的光照不同。 |
| P0 | 选择花盆和种子并播种 | 商店展示三种种子、三种盆器、价格与习性。选择空的已解锁位置，支付合计价格后出现对应盆栽。 |
| P0 | 查看盆栽的立体细节 | 点击场景里的盆栽或「细看盆栽」进入特写。鼠标拖动旋转、滚轮缩放，触屏支持拖动和双指缩放，并提供按钮和视角复位。 |
| P0 | 养护影响最终样子 | 湿度、养分和光照可以查看与调整。各品种有偏好，盆器影响排水。养护质量改变成熟体量和分枝数，异色改变花瓣或叶片颜色。 |
| P0 | 处理成熟盆栽 | 成熟后可售卖换叶币，或摆到花架上。两条路径均释放窗台位置，保留图鉴记录。花架最多陈列八株。 |
| P0 | 离开后还能继续玩 | 重新打开同一站点后，叶币、盆位、盆栽、图鉴和花架延续。离线时段补算成长，成熟植物会等待玩家回来处置。 |
| P0 | 给其他玩家看花架 | 从自己的花架生成只读分享链接，能访问相同游戏地址的朋友可以看展品和旋转盆栽。邻里页提供两处示范花架和本地喜欢。 |
| P1 | 感到自己的种植有积累 | 成熟自动点亮图鉴，记录次数、最佳品质、异色数量。首次开花、售卖、陈列等里程碑带来一次性叶币奖励。 |

## 回访动机与节奏

- **下一次回来有变化。** 发芽、展叶、孕蕾、成熟各有轮廓变化。光照时段和物种习性提示玩家尝试不同的窗台位置与盆器。
- **偏好能形成个人风格。** 玩家可以专收某种颜色、把花架按配色排序，或挑战同一物种的更高品质。成熟后随机确定异色，品质提高出现概率，所有品种都能正常开花。
- **忙时也能离开。** 无连续签到、任务倒计时或枯死惩罚。少量养护可提高品质，频繁浇水会使土壤过湿。资金不足且窗台清空时可领取练习种植包。
- **分享的门槛低。** 花架名片可直接打开。喜欢轻量且不附带货币奖励，玩家可以只看花。

## 后续需求

正式版优先验证自愿回访与种植反馈，再考虑更多花色、花盆、可换窗景、展陈主题、可选养护便签和无截止日期的收藏挑战。账号、云存档、花架索引、跨设备喜欢和访问隐私需要联网服务及相应验收。盆栽交易、聊天和排行独立评估，尤其要测量其对轻度节奏的影响。
