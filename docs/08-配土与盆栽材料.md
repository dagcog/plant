# 配土与盆栽材料

种植商店的「土壤与石材」出售可重复使用的库存。椰糠、腐熟堆肥、珍珠岩和浮石每次购买 100 份，雨花石、黄金麦饭石和陶粒每次购买一层。配土时按 5% 调整比例，可以填入该植物的推荐比例。自配土合计必须是 100%，每 1% 消耗 1 份库存。普通土无需购买。铺面和陶粒盆底独立于根区比例，可与普通土或自配土一起使用。

| 材料 | 游戏用途 |
| --- | --- |
| 椰糠 | 细软保水的纤维组分 |
| 腐熟堆肥 | 养分较多的有机质组分 |
| 珍珠岩 | 轻质的白色通气颗粒 |
| 浮石 | 适合偏干配方的多孔颗粒 |
| 雨花石 | 带纹理的圆石铺面 |
| 黄金麦饭石 | 暖金色细碎石铺面 |
| 陶粒 | 盆底滤水层，使游戏内水分散失增加 10% |

容器介质参考英国皇家园艺学会和宾州州立大学推广部门对保水、通气和颗粒介质的说明。推荐比例、加成和陶粒数值是游戏平衡参数。实际花盆的排水还取决于盆孔和介质，盆底加粗颗粒可能造成滞水。 [RHS 室内植物介质](https://www.rhs.org.uk/plants/types/houseplants/growing-media-houseplants) · [RHS 多肉与砾石铺面](https://www.rhs.org.uk/plants/types/cacti-succulents/houseplants/growing-guide) · [Penn State 盆栽介质](https://extension.psu.edu/potting-media-and-plant-propagation) · [Penn State 盆底排水说明](https://extension.psu.edu/debunking-garden-myths)

后端按材料目录核价，按请求编号防止重复扣款。购买材料会写入交易流水，播种时在同一事务内验证配方、扣除种子和花盆的费用、消耗库存并写入植株配方。成熟品质仍受光照、养分和湿度影响。推荐配方最高提高 25% 生长速度和 8 点品质，铺面只改变外观。花架保留植株的配方和铺面，访客只看到展品的材料。

内容版本 3 在打开旧窗台时启用，保留原有植株的内容版本，旧植株沿用普通土。生产 PostgreSQL 需要执行 `npm run db:migrate` 和运行角色授权脚本。 Blender 源文件、生成脚本及导出说明位于 [asset-sources/potting](../asset-sources/potting/README.md)。
